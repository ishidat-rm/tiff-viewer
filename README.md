# TIFF Viewer

VS Code extension for viewing 8/16/32-bit TIFF files without any external dependencies.

## Features

- 8-bit, 16-bit, 32-bit TIFF support
- Min/Max/Gamma contrast adjustment
- Multi-channel support (grayscale / RGB)
- Zoom (mouse wheel) and pan (Alt+drag)
- Pixel value display on hover

## Installation

1. Go to the [Releases page](https://github.com/ishidat-rm/tiff-viewer/releases)
2. Download `tiff-viewer-x.x.x.vsix`
3. Open VS Code
4. Press `Cmd+Shift+P` (Mac) or `Ctrl+Shift+P` (Windows/Linux)
5. Type `Extensions: Install from VSIX` and select it
6. Choose the downloaded `.vsix` file

## Usage

Open any `.tif` or `.tiff` file in VS Code — it will automatically open in TIFF Viewer.

- **Zoom**: Mouse wheel
- **Pan**: Alt + drag
- **Pixel value**: Hover over the image
